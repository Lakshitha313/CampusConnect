# 🎓 CampusConnect – College Event Explorer

## 📌 Overview
CampusConnect is a clean and responsive college event explorer website built using HTML and CSS. It provides students with a centralized place to explore upcoming college events, campus announcements, and student clubs through a modern and user-friendly interface.

## ❗ Problem Statement
Students often find it difficult to keep track of college events, important announcements, and student club activities when information is scattered across different platforms or notice boards.

## 💡 Solution
CampusConnect organizes campus events, announcements, and student club information in one place. Its simple navigation and responsive layout help students browse important campus updates easily.


## 🛠️ Technologies Used
- **HTML5** – Structures the webpage and its content.
- **CSS3** – Handles styling, layouts, responsive design, and hover effects.

## ⚠️ Current Limitations
- Campus events and announcements use sample static content.
- Dashboard statistics are not dynamically updated.
- Club buttons do not support actual registration.
- No JavaScript, backend, or database is integrated.It is built as a beginner frontend project to learn and practice the fundamentals of HTML and CSS while creating a clean, responsive college event explorer.

## 🚀 Future Enhancements
- Add JavaScript for interactive features.
- Implement event registration and club joining.
- Add search and filtering for college events.
- Integrate a backend and database to manage event information.
- Enable dynamic updates for announcements and dashboard statistics.
